# Next.js, not Angular, for the portfolio

The owner's deepest framework is Angular, but the site is built with Next.js. The site targets Full-Stack AI Engineer roles, where React/Next.js is the common stack. The AI Support Desk already runs on Next.js on Vercel, and the planned "Ask about my work" chat has better first-party streaming tools in the React ecosystem. Angular depth stays visible through the CV and Experience instead.
